### Урок: Работа с вложенными циклами и создание узоров в Python (модуль `turtle`)

**Теория: Вложенные циклы и построение сложных фигур**

В предыдущем уроке мы научились рисовать простые фигуры с помощью цикла `for`. Теперь разберём более сложную конструкцию — **вложенные циклы**.

**Вложенный цикл** — это цикл, который находится внутри другого цикла. Внешний цикл запускает внутренний, и тот выполняется полностью на каждой итерации внешнего.

**Синтаксис:**
```python
for i in range(n):  # внешний цикл
    # команды внешнего цикла
    for j in range(m):  # внутренний цикл
        # команды внутреннего цикла
```

**Как это работает:**
1. Внешний цикл начинает первую итерацию (`i = 0`).
2. Запускается внутренний цикл и выполняется `m` раз.
3. Внешний цикл переходит ко второй итерации (`i = 1`), и внутренний цикл снова выполняется `m` раз.
4. Процесс повторяется, пока внешний цикл не завершит все свои итерации.

**Пример: сетка из квадратов**
```python
import turtle

t = turtle.Turtle()
t.speed(0)  # максимальная скорость

for row in range(3):  # 3 строки
    for col in range(4):  # 4 столбца
        # Рисуем один квадрат
        for side in range(4):
            t.forward(50)
            t.left(90)
        t.forward(60)  # смещение для следующего квадрата
    # Переходим на новую строку
    t.penup()
    t.goto(0, t.ycor() - 60)
    t.pendown()

turtle.done()
```

**Важные нюансы:**
* Отступы критически важны: команды внутреннего цикла должны иметь больший отступ, чем внешнего.
* Переменные-счётчики (`i`, `j`, `row`, `col`) могут быть любыми, но лучше выбирать понятные имена.
* Команда `t.speed()` задаёт скорость рисования (от 0 до 10).
* Команды `t.penup()` и `t.pendown()` поднимают и опускают перо, позволяя перемещаться без рисования.
